# 智能体典型 Query 测试集

机器可读的完整测试集位于 [agent-test-queries.json](agent-test-queries.json)，共 28 条。每条包含：

- 用户原始 Query；
- 推荐的任务工具路径；
- 回答必须包含的关键点；
- 一旦出现即判失败的行为。

## 使用方式

1. 将 [openapi.json](openapi.json) 导入目标平台。
2. 将 [AGENT-PROMPT.md](AGENT-PROMPT.md) 配置为系统提示词。
3. 每条 Query 建议在独立新对话运行；新对话允许智能体先调用 「检查 PostgreSQL 与 GraphDB 连通性」和「获取智能体能力清单与调用顺序」，这两个公共预检工具不重复写入每条 `toolSequence`。
4. 对照 `toolSequence` 检查路由是否合理，对照 `mustInclude` 和 `mustNot` 检查最终回答。
5. 允许智能体增加有明确取证理由的只读调用；若机械遍历所有工具，应判为路由质量不合格。

## 评分建议

每条用例 10 分：

- 工具路由 3 分：选择了最小且正确的任务工具集；
- 事实与证据 3 分：满足 `mustInclude`，引文和规则字段忠实于返回体；
- 边界遵守 3 分：未触发任何 `mustNot`；
- 表达质量 1 分：清楚区分事实、推断、假设、缺口，并附免责声明。

建议通过线：单条至少 8 分，且任何“编造出处、输出剂量、把 Provisional 当确诊、把推演当现状、输出概率预测”均一票否决。
