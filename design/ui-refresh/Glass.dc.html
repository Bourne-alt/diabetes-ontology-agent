浅色玻璃体系

浅色调下玻璃仍然成立，但分层方式和深色版是反的：深色版靠描边和内高光，浅色版靠阴影。实测投影落差浅底 1.30:1、深底只有 1.08:1。第七节讲三维窗——那里的立体感来源同样和深色版完全不同。

一 · 背景层浅色也不能是纯色

原来的纸底 #f6f3ed 是纯色，半透明压上去只会变灰块。新背景是浅底 + 三团低饱和光晕 + 38px 网格，跨度控制在 1.27:1——足够让模糊可见，又不至于让玻璃在不同位置明暗不一。

--bg#f0f1f7底色，微冷。比原纸底更中性，好托住白玻璃
光晕 · 墨蓝rgba(52,71,122,.085)左上。alpha 只有深色版的五分之一——浅底上稍重就脏
光晕 · 墨绿rgba(74,124,116,.055)右上

二 · 三层白玻璃越关键越实

L1 · 容器

rgba(255,255,255,.60)

顶栏、面板背板、输入框。唯一带 backdrop-filter 的一层。

L2 · 卡片

rgba(255,255,255,.74)

结论卡、依据卡、图谱卡、气泡。透出 L1 已模糊好的结果。

L3 · 关键块

rgba(255,255,255,.90)

结论条、证据条目、警示块。接近不透明——这是语义。

三 · 层级靠阴影，不靠透明度浅色版比深色版更平

两栏用完全相同的三层不透明度。左边只有透明度，右边加了阴影、描边和语义色条。

实测
三层合成色 #efeff1 #f4f5f6 #fbfbfc——L1/L2 1.052:1，L2/L3 1.056:1。比深色版（1.066 / 1.082）还要平。
对策
阴影是浅色版的主力：L1 无阴影、L2 中、L3 强。再加描边三档（.08 / .11 / .14，深色半透明）和 3px 语义色条。 内高光用白色 inset，模拟玻璃上缘的反光。

四 · 禁止嵌套 backdrop-filter与深色版同

层背景模糊
L1 容器rgba(255,255,255,.60) backdrop-filter: blur(22px) saturate(1.5) —— 只有这一层
L2 / L3rgba(255,255,255,.74 / .90) 不设 backdrop-filter，透出 L1 已模糊好的结果
图谱窗内玻璃rgba(255,255,255,.78) 例外：它在 3D canvas 之上，自己模糊。仍是白玻璃——α 从 .60 提到 .78，因为底下会滚过实心节点
饱和度
浅色玻璃的 saturate() 要比深色版高（1.5 对 1.35）。白色叠加会冲淡底下的颜色，不提饱和度，背景光晕透上来就是一片灰。

六 · 性能、降级与打印

项做法
模糊层数量 全页 backdrop-filter ≤ 5 个：顶栏、面板背板、输入框、深窗顶栏、深窗图例。其余纯半透明。
别叠在动画上 深窗玻璃压着旋转的 three.js canvas，每帧重新模糊。动画运行时换不透明底，paused 时恢复。
滚动容器 玻璃层不要放在滚动容器内部；给滚动容器加 will-change: transform。
降级 @supports not (backdrop-filter) 与 prefers-reduced-transparency 都退到不透明。
打印 比深色版简单得多：去掉模糊与阴影，背景转纯白即可，语义色不用换。深窗仍需隐藏——3D 打印无意义。
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .l1 { background: #f7f8fb; }
}
@media (prefers-reduced-transparency: reduce) {
  .l1,.l2,.l3 { backdrop-filter: none; -webkit-backdrop-filter: none; }
  .l1 { background:#f7f8fb; } .l2 { background:#fbfbfd; } .l3 { background:#fff; }
}
@media print {
  .u { background:#fff !important; background-image:none !important; }
  .l1,.l2,.l3 { background:#fff !important; box-shadow:none !important;
                backdrop-filter:none !important; -webkit-backdrop-filter:none !important;
                border-color:#d6cdbd !important; }
  .gwin { display:none; }  /* 3D 窗打印无意义 */
}

七 · 浅色三维窗立体感来源和深色版完全不同

深色 3D 靠发光、高光、向暗处的深度雾。这三样在浅底上全部失效——发光等于把节点变淡，反而往后退。浅色 3D 的深度必须换一套来源。

深度线索参数说明
地面投影rx 13→7, α .16→.07 浅色 3D 的主力。每个节点在透视地面上留一个椭圆光斑，越远越小越淡。落差 1.39:1（近）到 1.15:1（远）
近大远小r 11px → 6.5px 比值 1.69，透视感足够又不失控
高度垂线虚线 2 3, α .20 从节点连到它的地面光斑，让「悬得多高」可量——这条同时承担语义
透视地面网格#d8dce8, 近疏远密 梯形网格给出基准面。没有它，投影会被读成「另一个节点」
深度雾≤ 20% 上限只有 20%，不是深色版那种 40%+
实测
雾 24% 时最弱的节点掉到 2.97:1，28% 时 2.77:1——低于图形元素所需的 3:1。 浅底上雾是向亮处融合，稍重节点就「消失」，和深色版向暗处融合的直觉正好相反。
节点
一律实心填充，不加 glow。五色按层雾化后仍在 3.18–7.65:1： #34477a 患者（0% 雾）· #48706a 实测（5%）· #6a7c69 概念（10%）· #816280 规则（15%）· #b17452 出处（20%）。
窗体
窗底 #eaecf4 与页面背景只差 1.046:1，单靠底色分不出窗—— 靠 inset 0 2px 15px rgba(28,26,23,.10) 做出凹陷感，像嵌在面板上的一块观察窗。
简化
窗改浅色之后，全站语义色只剩一套——原先深窗要单独维护一组提亮版（#8fa5e8 等五色）， 现在图谱、芯片、图例、打印全部共用同一套浅底色。这是这次改动省下的实际维护成本。
