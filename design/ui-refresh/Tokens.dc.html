迁移映射表

浅色调下，文字阶和语义色基本可以原样留用——真正要换的是「面」：纸底变成背景层，白卡片变成三层玻璃。这比深色方案省掉一大块工作。

一 · 新增：背景层唯一的新概念

原纸底 #f6f3ed 是纯色，半透明压上去只会变灰块。换成浅底 + 三团低饱和光晕 + 网格，跨度 1.27:1。

项值说明
--bg#f0f1f7 比原纸底更中性微冷，好托住白玻璃。暖象牙底会让白玻璃显得发黄
三团光晕.085 / .055 / .045 墨蓝左上、墨绿右上、赭石下方。alpha 只有深色版的五分之一——浅底上稍重就脏
网格rgba(28,26,23,.030) · 38px 玻璃感的来源。模糊需要底层有高频细节才能被看见，纯渐变底下模糊前后没差别

二 · 文字阶几乎原样保留

token动作三层玻璃上说明
--ink #1c1a17 不变15.1–16.8:1标题、结论正文
--ink-2 #413d36 不变9.4–10.4:1次级正文、证据标识
--ink-3 #555047 不变7.0–7.7:1说明文字
--muted #7b7468 → #6e6759 加深4.88–5.42:1旧值在玻璃上压线，加深后稳过 AA
--faint #a39b8c → #8a8271 降级3.32:1仅 ≥16px 或图标，不得放小字
--ghost #bdb5a5 禁文字1.66:1只做描边与占位符

这两处（--muted 加深、--faint 降级）和主题无关——原纸质版就该改，现在一并做掉。连带 .evt__seq、.counter、.composer__hint 这些用了 --faint/--ghost 的地方要改为 --muted。

三 · 语义色只有一处需要动

语义值动作L1 上覆盖的旧颜色
可核验 --indigo 不变8.26:1右栏青绿强调 15 种全归这里
未核实 --terra 不变4.91:1含右栏琥珀警示 8 种。文字改用 --terra-d
执行失败 --crimson 不变6.81:1含 .step-dot.failed #c2867c
判断规则 --plum 不变6.74:1图谱节点与芯片
检查与记录 --moss #3f6a63 加深5.57:1原拟 #4a7c74 只有 4.35:1，压线不过
本体概念 --olive #5c6f5a 新增4.96:1图谱节点与芯片

浅色调省下的一整块工作：这套语义色就是打印时要用的那套，不需要屏幕/打印两套并存。深色方案里必须维护「深底提亮版 + 浅底打印版」两份。

图谱窗也改成浅色后，全站语义色只剩这一套。先前深色窗需要单独维护一组提亮版（#8fa5e8 #5fb8aa #8fb589 #b98fb5 #e0995c），现在图谱节点、纸面芯片、图例、打印全部共用上表。窗内只按深度做 ≤20% 的雾化，色相不变。

四 · 面、线、影这才是主要改动

原玻璃版说明
--paper #f6f3ed→ --bg + 光晕 + 网格见第一节
--surface #ffffff
--surface-2 #fcfaf6		→ L1 .60 / L2 .74 / L3 .90 按容器／卡片／关键块三选一。不再有「白底」这个概念
--line / --line-2 / --hair→ rgba(28,26,23,.08/.11/.14) 描边改为深色半透明，三档对应三层
--indigo-soft #edf0f7
--terra-soft #fbf0e6		→ rgba(52,71,122,.10)
rgba(163,86,42,.10)		 改为语义色低透明度叠加，这样在任何玻璃层上都成立
--shadow（单档）→ 三档 + 白色内高光 阴影是浅色玻璃的分层主力（落差 1.30:1，深色版只有 1.08）。L1 无影、L2 中、L3 强，配 0 1px 0 rgba(255,255,255,.7) inset 模拟上缘反光
圆角 6 / 8 / 10px→ 8 / 9 / 12px玻璃需要略大圆角承托，仍不用胶囊形
saturate（无）→ saturate(1.5) 白色叠加会冲淡底色，不提饱和度光晕透上来就是一片灰。比深色版的 1.35 更高

时间紧的话可以只做 P0：背景层 + L1 容器玻璃（顶栏、面板背板、输入框），约 1 天。视觉上已经八成是玻璃，卡片和关键块先沿用不透明白底——因为浅色版的 L2/L3 本来就接近白色，中间态不违和。这是浅色调相对深色的又一个好处。
