三 · 玻璃验收十二条，逐条打勾

项要求验收方式
背景层底色 + 3 光晕 + 网格 去掉网格层截图对比——如果模糊前后看不出差别，说明玻璃没生效
模糊层数量≤ 5 个 DevTools 搜 backdrop-filter，超过 5 个就是嵌套了
禁止嵌套仅 L1 带 filter L2/L3 不得有 backdrop-filter；边缘出现脏环就是嵌套了
层级可辨阴影三档 + 描边 灰度截图下三层仍要分得出来——只靠透明度分不出（1.052 / 1.056:1，比深色版还平）。浅色版阴影是主力
关键块不透明度L3 = .90 未核实警示块不得低于 .90；透明度在这里是警示强度
图谱窗内玻璃白玻璃 .78 把图谱拖到最深的患者节点压在玻璃条下的位置截图，深字仍须清晰（α=.62 时次级文字掉到 4.08，不够）
三维深度雾≤ 20% 最远层节点仍须 ≥3:1。24% 时最弱的掉到 2.97——浅底上雾是向亮处融合，稍重就消失
三维深度线索投影 + 近大远小 节点不得加 glow——发光在浅底上等于变淡，反而后退。深度靠地面投影（rx 13→7）与半径（11→6.5）
窗体凹陷inset 阴影 窗底与页面背景仅差 1.046:1，必须靠内阴影分出窗体轮廓
动画时降级换不透明底 未 paused 时深窗玻璃改不透明；低端机实测帧率
不支持时降级不透明，非半透明 @supports not (backdrop-filter) 必须退到实色
系统偏好reduced-transparency 开启后全部转不透明；reduced-motion 规则保留
打印样式表去模糊去阴影 实际打印一页证据。浅色版语义色不用换，图谱窗隐藏即可
文字阶最低 4.88:1 --muted 需加深至 #6e6759；--faint 仅 ≥16px；--ghost 不得承载文字
纵轴语义按 KIND 分层 节点不再按数组下标排布；界面说明同步改掉「位置不代表风险高低」

第四条是最容易漏的。把界面截图转成灰度看一眼——如果结论卡、证据卡、警示块在灰度下糊成一片，说明层级全靠颜色在撑，色觉障碍用户会完全分不出「已核验」和「未核实」。这在医疗工具里不是可用性问题，是安全问题。

四 · 落地顺序全站换肤，和只收编右栏差一个量级

P0
背景层 + L1 容器玻璃

底色、三团光晕、38px 网格，加顶栏／面板背板／输入框三处 L1。约 1 天。

做完这一步视觉上已经八成是玻璃。时间紧可以就停在这里——浅色版的 L2/L3 本来就接近白色，卡片先沿用不透明白底不违和。

P1
L2 / L3 分层与阴影体系

卡片与关键块的玻璃层，加阴影三档、描边三档、语义色条。约 1 天。验收看灰度截图那条——浅色版三层亮度差只有 1.05，全靠阴影撑。

P1
面与线的替换

右栏 133 种硬编码按迁移表归并，--muted 加深、--faint 降级、--moss 加深，.answer__body.markdown 改回衬线。约半天。

文字阶和语义色基本留用，这块比深色方案省下约 1.5 天。

P1
让节点坐标承载信息

GraphScene.jsx:35 的 position(index, count, kind) 现在按数组下标排螺旋，所以代码里才写着 Coordinates carry no clinical meaning。改成按 kind 分层：纵轴自下而上是 患者 → 实测数据 → 本体概念 → 判断规则 → 指南原文。半天，改一个函数。

换玻璃是观感，这条才决定 3D 值不值那 43% 屏宽——改完「这个球说明什么」才有答案。

P2
降级与打印

@supports、prefers-reduced-transparency、@media print 三套分支。约半天。

浅色版打印简单得多：去模糊去阴影、背景转纯白即可，语义色不用换。但别当可选项——这是医疗工具，证据页要能打出来归档。

合计约 3 天——比深色方案省约 1.5 天，省在文字阶和语义色基本留用、打印样式不用维护第二套。如果演示在即，P0 停手（约 1 天）是个合理的中间态。
